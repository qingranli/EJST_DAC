## R Code Scripts

The data preparation script should be run first; all plotting scripts depend on its outputs. The two regression scripts should be run before the scripts that plot Figure 3 and Figure 4.

### Step 1 — Data Preparation

**`Data Prepration in R/Rcode Data Preparation.R`**

Builds all derived datasets used by the analysis scripts. Specifically, it:

1. Constructs crosswalks between 2010, 2019, and 2020 census tract boundaries using area-overlap matching and the NHGIS crosswalk file.
2. Cross-matches DAC designations from CEJST, DOE, and DOT into a single US-wide dataset, and from all four tools (including NYS) for New York State.
3. Downloads 2020 decennial census data (total population; racial/ethnic composition) via the `tidycensus` package and computes population density and group shares.

**Outputs:**
- `crosswalk_tr2010_tr2019.rds` — matched tracts (2010 and 2019 maps)
- `crosswalk_tr2020_tr2010.rds` — matched tracts (2020 and 2010 maps)
- `DAC_US_merged.rds` — US-wide merged DAC designations
- `DAC_NY_merged.rds` — New York only merged DAC designations
- `US_tr2020_demography.rds` — 2020 Census demographics for all US tracts

---

### Step 2 — Regression Analyses

**`Linear Regression (for Fig 3 data).R`**

Runs post-LASSO linear regression predicting each tool's cumulative **Score Percentile** from its EJ indicators, separately for DOE, DOT, and NYS. LASSO variable selection uses 10-fold cross-validation; results are saved for both the 1-standard-error lambda (used in Figure 3) and the minimum-error lambda (used in SI Figure 4).

**Inputs:** `DAC_score_DOE_long.rds`, `DAC_score_DOT_long.rds`, `DAC_score_NYS_long.rds`, `EJ_index_DAC_DOE.rds`, `EJ_index_DAC_DOT.rds`, `EJ_index_DAC_NYS.rds`, `DOE_data_cols.csv`, `DOT_data_cols.csv`, `NYS_data_cols.csv`

**Outputs:**
- `Score_postLasso_1SE.RData` — regression objects for 1SE lambda
- `Score_postLasso_minE.RData` — regression objects for min-error lambda

---

**`Logistic Regression (for Fig 4 data).R`**

Runs post-LASSO logistic regression predicting **binary DAC designation** from EJ indicators, separately for CEJST, DOE, DOT, and NYS. Tribal-designated DAC tracts (from CEJST) are excluded before fitting. Results are saved for both lambda selection rules.

**Inputs:** `EJ_index_DAC_CEJST_binary.rds`, `EJ_index_DAC_DOE.rds`, `EJ_index_DAC_DOT.rds`, `EJ_index_DAC_NYS.rds`, `crosswalk_tr2010_tr2019.rds`, `crosswalk_tr2020_tr2010.rds`, `tracts2010_tribal_CEJST.rds`, `CEJST_data_cols_binary.csv`, `DOE_data_cols.csv`, `DOT_data_cols.csv`, `NYS_data_cols.csv`

**Outputs:**
- `DAC_postLasso_1SE.RData` — logistic regression objects for 1SE lambda
- `DAC_postLasso_minE.RData` — logistic regression objects for min-error lambda

### Step 3 — Figures

**`Plot Figure 1 and Figure 2.R`**

Produces the two main manuscript maps.

- **Figure 1** (`Figure_save/main_Figure 1.pdf`): US choropleth map showing the percentage of DAC-designated census tracts in each state, faceted by tool (CEJST, DOE, DOT).
- **Figure 2** (`Figure_save/main_Figure 2.pdf`): Figure for New York State — (a) census tract map colored by number of DAC designations, with NYC inset; (b) tract counts by urban/rural status and DAC count; (c) population by urban/rural status and DAC count.

**Inputs:** `DAC_US_merged.rds`, `DAC_NY_merged.rds`, `data_raw_NY_DAC_map.csv`

---

**`Plot Figure 3 and SI Fig 4.R`**

Plots the top 10 EJ indicators from the post-LASSO **linear regression** (Score Percentile ~ indicators), one panel per tool (DOE, DOT, NYS). 

- **Figure 3** (`Figure_save/main_Figure 3.pdf`): Uses 1SE lambda results.
- **SI Figure 4** (`Figure_save/SI_Fig 4.jpg`): Uses min-error lambda results.
- Saves full regression tables to `Figure_save/RegTable_score_1SE_save.csv` and `Figure_save/RegTable_score_minE_save.csv`.

**Inputs:** `Score_postLasso_1SE.RData`, `Score_postLasso_minE.RData`, `DOE_data_cols.csv`, `DOT_data_cols.csv`, `NYS_data_cols.csv`

---

**`Plot Figure 4 and SI Fig 5.R`**

Produces forest plots of the top 10 EJ indicators from the post-LASSO **logistic regression** (DAC ~ indicators), one panel per tool (CEJST, DOE, DOT, NYS). Odds ratios and 95% confidence intervals are shown; bars are color-coded by EJ category.

- **Figure 4** (`Figure_save/main_Figure 4.pdf`): Uses 1SE lambda results.
- **SI Figure 5** (`Figure_save/SI_Fig 5.jpg`): Uses min-error lambda results.
- Saves full regression tables to `Figure_save/RegTable_1SE_save.csv` and `Figure_save/RegTable_minE_save.csv`.

**Inputs:** `DAC_postLasso_1SE.RData`, `DAC_postLasso_minE.RData`, `CEJST_data_cols_binary.csv`, `DOE_data_cols.csv`, `DOT_data_cols.csv`, `NYS_data_cols.csv`

---

**`SI Fig 1.R`**

Produces **SI Figure 1** (`Figure_save/SI_Fig 1.jpg`): two regional maps of New York State (Mid-Hudson Valley and North Country) showing census tracts classified by Energy Burden and Socioeconomic Burden profiles, with DOE DAC designation overlaid and an OpenStreetMap basemap.

**Inputs:** `DAC_US_merged.rds`, `EJ_index_DAC_DOE_v2.rds`, `DOE_data_cols.csv`, county boundaries downloaded via `tigris`, basemap tiles via `maptiles`

---

**`SI Fig 2.R`**

Produces **SI Figure 2** (`Figure_save/SI_Fig 2.jpg`): correlation plots between DAC designation (by tool) and population demographic variables, shown separately for New York State and the full US.

**Inputs:** `DAC_US_merged.rds`, `DAC_NY_merged.rds`, `US_tr2020_demography.rds`

---

**`SI Fig 3.R`**

Produces **SI Figure 3** (`Figure_save/SI_Fig 3.jpg`): six-panel scatter plots of normalized cumulative score vs. score percentile rank for DOE, DOT, and NYS, faceted by DAC designation and colored by urban/rural classification.

**Inputs:** `DAC_score_DOE_long.rds`, `DAC_score_DOT_long.rds`, `DAC_score_NYS_long.rds`, `DAC_US_merged.rds`

## Data Files

These files contain DAC designations and EJ indicator values downloaded or derived from the respective screening tools. 

| File | Format | Description |
|------|--------|-------------|
| `EJ_index_DAC_CEJST_binary.rds` | RDS | Binary DAC designation and EJ indicators from CEJST; 2010 census tract boundaries |
| `EJ_index_DAC_DOE.rds` | RDS | Binary DAC designation and EJ indicators from DOE; 2019 census tract boundaries |
| `EJ_index_DAC_DOT.rds` | RDS | Binary DAC designation and EJ indicators from DOT; 2020 census tract boundaries |
| `EJ_index_DAC_NYS.rds` | RDS | Binary DAC designation and EJ indicators from NYS; 2019 census tract boundaries |
| `DAC_score_DOE_long.rds` | RDS | Raw cumulative scores and percentile ranks for all DOE census tracts |
| `DAC_score_DOT_long.rds` | RDS | Raw cumulative scores and percentile ranks for all DOT census tracts |
| `DAC_score_NYS_long.rds` | RDS | Raw cumulative scores and percentile ranks for all NYS census tracts |
| `tracts2010_tribal_CEJST.rds` | RDS | CEJST tracts designated DAC solely on the basis of tribal status |
| `data_raw_NY_DAC_map.csv` | CSV | Raw NY state demographic and classification data used in Figure 2 |
| `CEJST_data_cols_binary.csv` | CSV | Indicator metadata for CEJST (column names, display names, EJ category) |
| `DOE_data_cols.csv` | CSV | Indicator names and descriptions for DOE |
| `DOT_data_cols.csv` | CSV | Indicator names and descriptions for DOT |
| `NYS_data_cols.csv` | CSV | Indicator names and descriptions for NYS |
